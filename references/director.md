# 导演镜头决策

## 从叙事任务推镜头

先读 [视觉风格路由](visual-style.md)。有剧情直接推导风格与情绪，给出六项视觉参数包；不让用户选姓名，也不等待常规审美选择才开始分镜。

每场先写：实际事件、人物关系变化、观众此刻知道什么、结束时应知道/感受什么。按发现、确认、反应、决定、行动、后果拆节拍；一个节拍不等于固定一镜。文本与独立发声生成节点先按[完整句边界](workflow.md#剧本拆分的完整句边界)确定，一句一个节点；句内可以设计画面变化，不能将半句话另建节点。

先安排人物与道具如何移动，再设计观众从哪个位置看见它。镜头表至少包括：

`shot_id / section_id / 叙事目的 / 新信息 / 时长 / 主体动作起止 / 风格与材质 / 色调与物体配色 / 起落构图 / 景别与机位 / 运镜起止、触发与节奏 / 焦点策略 / 光线可见结果 / 视线与轴线 / 接镜方式 / 声音 / 生成风险与备用`

不要为变化而塞入景别，也不要机械套“全景→中景→特写”。相邻镜头重复信息时，合并或用新的反应、证据、关系变化重设计。静止镜头也可以承担高潮。

## 默认交付专业分镜表

这是[制作主流程](workflow.md#制作阶段与审核顺序)第3步的交付规范：先交传统文档剧本并取得用户对具体版本的通过，再制作Excel多列专业分镜表，逐镜一行。新项目的第一份交付不直接跳到分镜或白模；已有获审分镜沿用，不重复要求重做文档。用户另给模板时沿用，表前给六项视觉参数包和场次基线，不能只有镜号概要或把必需设计藏进长篇附件。

**核心主表是单一当前交接入口**：打开这一张表，接手者应能按同镜号读懂必要分镜、复制当前完整视频词、找到实际选中的首帧与四类参考，并还原输入节点、依赖和生成设置。主表不是概要目录，不能要求接手者在多张平行表中自行拼出当前版本。按项目需要组织列组、冻结标识列或按场次纵向分段，不固定镜数、列数或工作表数量。

主表A列统一为“镜号／时间”：同格分行展示镜号、全局起止时间和已知帧数／帧率，默认不再单列“入点（秒）”“出点（秒）”“帧数”。例如 `G001 / 00:00—00:05 / 120帧（24fps，规划）`；24fps仅为示例，帧率未核实时不猜算帧数，规划时间不标成实际剪辑时间。用户原有的“时长（秒）”列可保留；无独立时长列时将时长并入A列，不重复铺设同义栏目。用于计算、剪辑和真实尾帧接力的精确源入出点、时间基准及解码帧号仍保存在制作记录中，不因主表合列而删除。用户明确指定其他模板时遵循其要求，不强制凑成12列。

“参考对应”只表示本镜到素材的索引与职责，例如“人物C04用于身份，场景E03用于空间”；它不是首帧、尾帧或必备栏目。人物、场景、表情、物品四类参考已经明确时，默认不再增加重复的汇总索引列。确需跨表查找时可保留简短资产ID、职责和入口，不往这一列混入旧候选、回收记录或执行日志；调整已有模板中的该列须遵循用户授权范围。

主表按同一镜号保留以下内容；这是内容职责，不是强制列数：

1. **必要分镜设计**：镜号／时间｜叙事任务与情绪节拍｜景别、机位与镜头选型｜起落构图与空间｜主体动作与表演｜运镜、焦点与节奏｜必要风格、色调、配色及光影｜台词与声音｜切点与承接。构图单列，写主体位置/大小、前中后景、视线留白、遮挡与透视怎样改变。风格、色调、配色和打光保留各自语义，不用一个“冷蓝电影感”包办；详细美术说明可入附表，执行所需的本镜条件仍须在主表可读。
2. **当前完整视频提示词**：镜号/片段号、选中版本、完整正文、对白/声音及针对性负向约束、适配状态与审核状态。一个单元格可容纳完整正文，也可在同一主表用同镜号连续块承载；不得只给链接、摘要或要求另表拼接。只有相应版本已获用户审核且所需输入/能力已核实，才能标为“最终可执行”；尚在规划、缺参考或待上游真实尾帧时，展示当前完整规划并明确缺口，不能改名冒充最终版。
3. **当前选图与参考节点**：实际选中首帧及“人物参考｜场景参考｜表情参考｜物品参考”四栏，分别含实际图片、名称或资产ID、选中版本、指纹与本镜职责。人物传身份和服装，场景传空间与环境，表情传该镜神态而不改身份，物品传形制、材质和具体内容。四类参考不能只放在附表，也不把物品并入场景；无独立参考时写“无/不适用”及原因。首帧只嵌入当前已选类型，已有合格正式图不再额外生成白模；缺图明确标缺失，不能贴占位图冒充产物。
4. **复刻所需的连接与设置**：主表记录参考顺序、可复用节点ID/职责、首帧与图像/音频参考到目标视频的依赖关系、`continue/reangle/cut/reset`及上游选版；保存已实际创建的平台/项目、资源ID、节点ID、边ID和就绪状态。未上传、未创建或未连线就如实注明，并用项目内稳定ID描述待创建的关系，不虚构平台ID。生成设置包括实际平台/模型及可得版本、模式、画幅、时长、分辨率、参考槽位和音频方案；种子、帧率等只记录实际支持且已知的值，未知项、审核范围和阻塞项明确列出。主表的“可复刻”指资料和流程可接续，不保证随机模型输出像素相同。

交接必须可离开原电脑使用：Excel嵌入选中图片，并提供对应原尺寸素材的可导出原图或随包文件；仅嵌缩略图时，必须同时随包提供原图。文件入口采用交接包内相对路径或接手者有权限的稳定链接，记录与选版相同的指纹；原电脑绝对路径只能作来源记录，不能是唯一入口。平台节点即使在当前账号可用，也须有资产ID、图片和连接职责的映射，不能只给他人无权访问的节点号。换电脑后按这些资料验证素材可取、词可复制、节点可重建；能力或权限缺口保留真实状态。

**附表支撑主表，不另设第二套当前入口**：按实际规模保存六项视觉参数与场次/逐镜美术基线、完整原稿及原文到镜号/声轨的映射、资产来源与专业物品完整提示词、规划和历史词、实际生成调用与选版证据、旧图复用和回收历史。视觉基线可与逐镜美术同表分区；历史材料按版本归档，不删除真实执行原词。专业物品附表按同资产ID展示清楚的正视/展开/局部内容稿、完整可复制的资产提示词和核验状态，主表仍展示该镜最终选中的物品参考与职责；详见 [物品参考与专业内容稿](generation.md#物品参考与专业内容稿)。

叙事摄影、视觉美术、完整提示词三类设计语义都要保留，不能把三类语义误当必须并列交付的三张表。稳定规则集中维护，每行写本镜实际呈现，不用“同上”代替可审阅内容；可复制的视频词须展开其需要的已知条件。当前词和选版只有一个维护源，主表是当前视频词的权威单元格；附表或平台的必要复用展示由它同步并逐字核对，不能双处独立改写。原始实际调用记录属于历史证据，不随当前词覆盖。

每个逻辑镜头对应一条独立记录，长词可按同镜号展开连续块，工具生成片段号另记。先按句意、动作起落、信息揭示与听者反应确定观察单位，再分配时间；不按字数、逗号或等分秒数机械凑镜。场次/叙事段时长不直接等于单镜时长。**默认每个视频生成片段为 4–8 秒**；用户或项目另行写明范围时使用该范围，并留存书面依据。4–8 秒约束每一个生成片段，不得用完整句聚合、工具支持更长时长或“有叙事理由”绕过；逻辑镜头超过 8 秒时拆成多个连续片段，后续片段使用真实尾帧，旁白另行跨切连续。用户只指定理想值时，完整表演、揭示或读字有可观察理由可超过理想值，但不能把任何显式硬上限当建议；不能延长静图或空等凑时长。少于 4 秒应重组织节拍，超过当前上限应重设计或拆段。规则变更后回看真实切点与完整行为，不能只改校验上限却保留旧的机械拆镜。每次切镜交代相应的新观察构图与承接的动作状态，不用重复同图或重新表演上一阶段凑短镜。完整句所属声音可跨合理画面切点连续，但不得拆成半句发声节点；全文按当前范围逐字保留，不新增对白、不让每个子镜重读整段旁白。时间码、秒数与全场总长要相符；焦距须有画幅或参考假设，未量测的灯位/强度标规划；不伪造预览、实拍参数或验收状态。

聊天与保存脚本使用相同镜号和版本；主表直接展示每镜当前完整视频词及最终参考，其他提示类型、长篇来源和调用证据按上述附表职责保存。不能只给链接、JSON、提示词摘要、“同上/同前/按基线”、变量占位或一个镜头示范。已知全场设定在各条复制使用的提示里展开；必要参考图作为明确附件，文件路径不是图片输入。费用、接口请求体和任务日志可另放制作记录。极简任务可以缩短每格文字，不能丢掉用户要求的视觉设计。长片可按场次分段或分页，仍提供统一主表入口，不以表太长为理由只交局部。

完整写法见 [专业分镜表示例](storyboard-example.md)。示例用于展示栏目与描述细度，不把其镜数、时长、焦距、配色或悬疑风格套到其他项目。

## 四类参考怎么分

主表的“人物参考｜场景参考｜表情参考｜物品参考”四栏按“这东西能不能单独拿出来做”分，不按它在剧情里重不重要分：

- **人物参考**：身份与服装。可移动的佩饰、手套、帽子、眼镜、纹身与疤痕跟着人走，写在人物身上，不单列物品。
- **表情参考**：该镜的神态，换脸不改身份，不承担服装与空间职责。
- **物品参考**：能脱离身体独立存在、需要单独制作或单独出图的东西——武器、护具、法器、容器、信物、工具，以及场景里摆着但能搬走的家具、灯具、旗帜、载具。
- **场景参考**：搬不走的环境本身——墙、地、顶、门窗开口、山体、河流、植被、固定建筑结构与天光天气。

判断只有三问：能不能离开这个空间单独存在（能→物品）；是不是人的身体或随身装饰（是→人物）；拆掉它场景就变了（是→场景）。同一件东西只能有一处归属，跨栏重复会让生成时出现两套外观。

群像角色（士兵、侍卫、仪仗、随行仆从）不逐个建人物资产，用一份制式描述：年龄区间、性别构成、统一发式、制服形制与配色、配发装备；只有需要单独露脸的个体另立人物资产。

## 表演也编译成可执行字段

涉及人物/角色时读 [performance-compiler.md](performance-compiler.md)：从原稿直接推导具体触发、可见部位与逐拍主动作，语音参数与原文台词分别保存。把初态→触发→落点、听者反应和主要语音变化填入主表“动作与表演”“台词与声音”列，完整提示词包按同一镜号/版本保存，同时在脚本逐镜提示词表展示；不能只在外部JSON存在。远景或暗侧不强塞不可见的眼部细节，不把有意停顿列为表演错误。自动结构报告不证明观众看懂或模型已演出。

## 场次先有视觉递进

多人及危险场景按[多人调度与危机反应](performance-compiler.md#多人调度与危机反应)逐人/逐组设计动作阶段，把紧张感落实为可见反应；共同撤离方向仍保留姿态、视线和节奏差异，并分别验首尾状态。

先用几句话确定这一场的观察立场与变化：观众贴着谁经历事件、何时比角色多知道一点、人物权力关系怎样改变、空间从开放到受限还是相反、画面节奏在何处收紧或停住。把构图、焦点、运动与光线放在同一条叙事线上；动作快不自动要求摄影机更晃，人物停住也不等于镜头必须停住。

对承担转折的关键镜头比较适合的方案，例如固定构图等待事件发生，或移动摄影机逐步揭示信息；用新增信息、情绪与空间收益选择。每场形成自己的视觉规律及有意打破规律的时刻，不机械规定运动镜头比例，也不默认所有镜头都是慢推、环绕或浅景深。

## 场次先锚定空间

同一场戏的所有镜头共用一套空间参照物，否则观众和模型会从第二个机位开始重新猜这个房间。开拍前给这场戏定一份锚点清单：名称用中文实义词（入户门、大窗户、三人沙发、右侧巨橡），写清它在空间中的位置和可辨识特征；再写每个人的初始位置、面朝方向、与两侧锚点的关系。

- 锚点在整场里位置不变，跨镜只改变观察角度，不改布局。确实需要改布局时按新场次或明确的时间断点处理。
- 方位必须绑锚点。「人物在房间左边」不合格，「人物站在入户门前、面朝大窗户」合格；「镜头从侧面拍」不合格，「机位在三人沙发后方、越过人物A的肩拍向入户门」合格。没有参照物的左、右、旁边、对面不写。
- 人物移动用锚点路径写：从入户门走向大窗户，途中经过茶几。
- 机位会覆盖多个角度时，再补一两句从主要角度看到的画面，避免第二、第三个机位重新发明空间。复杂空间的精确尺寸、遮挡和可行机位仍交给三维预演或实测。
- 锚点清单与初始状态放在场次基线或附表，主表照常写每镜实际可见的关系，不另开一份平行文件。未量测的距离、方位和层高标为规划，不写成实测。
- 原文里的感受词要翻成看得见的状态：写「潮湿发霉」就是墙角霉斑、地面返潮发暗、木料起翘；写「阴森」就是光源偏冷且弱、墙面剥落、门敞着而里面看不出深浅；写「热闹」就是人群密度、叫卖摊位和挂满的幌子。翻不成可见状态的形容不进分镜。

## 把运镜写成能执行的画面变化

每个有运动的镜头写清下列关系；固定镜头同样写明停住观察什么。具体内容进入用户直接阅读的逐镜正文，不只藏在提示词、JSON或风险备注里。

1. **起幅与落幅**：从什么高度、方向、景别和遮挡开始，最后把谁与什么关系放进画面；前景、中景、背景分别承载什么，落幅让观众新看见什么。
2. **运动动机与触发**：由角色起步、目光变化、威胁入画、声音或情绪转折中的哪一刻启动；何时跟随、何时领先或故意滞后。不能只填“增强电影感”。
3. **路径、轴线与速度**：摄影机实际往哪里移动、围绕什么、经过哪些遮挡；从静止进入匀速、加速或停留的节奏与动作对应。连续复合运动可以分阶段设计，但每阶段须有目的与空间连续性，不把互不相干的推拉摇绕堆进同一片段。
4. **镜头与焦点**：焦距结合画幅/传感器、物距与画面占比选择；未知时说明假设或用可见构图描述。机位移动会改变透视关系；原地变焦主要改变取景，不能把整图放大冒称空间推进。移焦（清晰位置从一个对象转到另一个对象）交代两个对象、触发与观众注意力变化，不能同时承诺所有层次始终清楚。
5. **停住与切出**：运动何时完成、落幅留多久让表演或线索被读到；在动作、目光或声音的哪个接点切走，下一镜接住什么。续接片段只沿既定运动继续，不在工具分段处自动停稳再起动。

运动幅度、焦距、速度、秒点是有依据的设计值或预演数据；没有量测时不伪称精确。提示词不能保证模型硬执行轨迹，工具适配见 [generation.md](generation.md)。

## 高级运镜、对焦与时间设计

涉及甩镜、主观移动、360°环绕、移焦、变速推进、细节到全景、上升环绕、前景擦过、慢镜头或复合镜头时，按 [高级镜头语言库](camera-language.md) 读取相应类型及联合质检。先从剧情选择，再编译成可见变化；不把术语目录变成每场必须集齐的清单。

分镜“运镜、焦点与节奏”格写明所选类型与触发、起幅/揭示点/落幅、世界路径/范围、速度分段、焦距和焦点、落幅停留及切点；较长时另设同镜号运动窄表。时间变速单列源动作与输出时间的对应、对白和声音处理。摄影机加速、变焦、移焦、时间变速互不替代，完整动作词与负向约束仍须逐镜全文入表。

复合镜头按有目的的阶段组织，超长拆段保持运动相位和真实尾帧；无发声时按动作组织，含人声时不得截断[完整句节点](workflow.md#剧本拆分的完整句边界)，完整句放不进硬上限则说明冲突并调整方案。整周/高位运动需检查新出现的视角、空间、光向与连续跨轴，不套“永不越轴”来删除所需轨迹。静帧只能检查该时刻构图，不能声称验证了甩镜落点、环绕路径、移焦或慢动作。

## 运镜与打光共同进入脚本

先读 [lighting.md](lighting.md)，为场次建立光源与明暗基线，每镜继承并写出本镜能看见的效果。每镜在分镜表对应单元格中直接交付以下内容，稳定设定通过基线引用复用：

- 叙事任务与情绪变化、起幅/落幅、主体动作与目光。
- 摄影机路径、触发/速度/停留、焦点策略、为什么此刻移动或保持固定。
- 本镜如何落实媒介/材质、整体色调、物体配色与构图规律；有意变化要对应情绪节拍，不能每镜换一套滤镜。
- 主光的实际来源与方向、主体和背景的明暗/光质/色彩关系，以及人物运动后怎样进入或离开光区；本镜无变化就说明保持哪项关系。
- 台词与声音、实际切点和下一镜的承接、关键生成风险及保留叙事作用的备选。

“35mm＋缓慢推进＋电影光”不构成完整镜头。检查正文是否能让另一个人复述：观众先看哪里，事件发生时画面怎样变化，最后为何停在这里。无法回答时先重设计，不靠追加术语填满表格。完整设计可以比单次生成更丰富；将设计拆成可控片段时保留原叙事目的，不能静默把全部镜头退化为同一种运动。

## 镜头选择表

| 观众任务 | 可考虑 | 必须证明 |
|---|---|---|
| 理解人物、出口、危险之间的距离 | 建立镜头、关系镜头 | 关键位置关系能被看懂 |
| 看清决定或微小反应 | 面部近景/特写、停留 | 表情变化可见，有前后语境 |
| 确认线索或物体状态 | 道具插入特写 | 物体此前存在，持物手和状态正确 |
| 经历人物的发现 | 视线→对象→反应 | 看向谁与看到什么有对应关系 |
| 注意力逐渐收紧 | 缓慢推进或收紧构图 | 新细节或表演随运动被揭示 |
| 从局部理解更大后果 | 拉远揭示 | 新出现的空间带来信息 |
| 体验认知崩塌或眩晕 | 滑动变焦 | 主体大小基本不变，背景透视变化可见 |
| 跟随人物穿越空间 | 跟拍、长镜头 | 路线、障碍、揭示有连续意义 |

这些是条件性选择，不是“低角度必强、特写必悲伤”的固定公式。参考片只迁移机制，不逐格照搬其镜头顺序。

## 什么时候不给脸

镜头由句意、动作起落和信息揭示决定，不为凑比例安排空镜；但脸用多了会钝化，同一个情绪反复给脸，观众反而不看。连续几个镜头都以脸为主体时，停下来问一句：这一步真的需要脸吗。

同一句台词的完整节点内部可以设计非人物画面切点（画外音连续）：场景里的物件特写、局部肢体（手、肩、脚步）、光影变化、环境空镜、不露脸的听者反应。不能把该句文字分摊到多个独立生成节点；平台无法在单节点实现所需切点时调整画面方案。每个非人物切点过三问：它承载了什么信息或情绪；换成脸是不是更差；删掉它叙事会不会断。答不上来就删，不为穿插而穿插，也不要为凑数切一个和当前情绪无关的空镜。

反过来，必须有脸的场合不要躲：定场交代谁在场、过肩正反打建立关系、双人同框交代关系转折、情绪爆点、关键动作的完成、权力关系的建立。该给脸时用非人物代替，会削弱事件本身。

长台词先按原文完整句划分节点，再在各节点内部用上述非人物切点或动作变化组织观察，随后考虑另一个人的反应；不能在逗号、顿号或自然停顿处截断一句。同一段台词里的画面切点不全是脸。

## 滑动变焦的执行约束

执行规则、完整视频词、检查点与回退统一维护在 [M11｜滑动变焦](camera-language.md)。核心是机位移动与反向焦距变化配合、主体占幅近似稳定和背景纵深关系改变；整图缩放不构成这种空间效果。涉及此类型时读取M11，不重复维护两套规则。

## 连续性、剪辑与动作

- 对话先定义主关系轴和可用机位区；视线应指向正确对象。越轴可有意设计，但要有空间重置或可感知的理由。
- 换机位时角色在屏幕上的左右可能改变。保持世界坐标、朝向、持物手与轴线逻辑，不要求新角度机械保留所有二维像素位置。
- 切在动作上可以连接“伸手→接触→结果”；动作阶段不得无意回退或重复。时间跳转要明确。
- 同一主体的两个相邻镜头，机位角度与焦段合起来要有明显差异，否则观众会觉得画面被突然怼近；差异靠换角度、换焦段或跨两级以上景别实现，不靠调色区分。
- 相邻镜头的景别跨度太大时加过渡：插入一个中间景别，或者用动作、视线、形状匹配接住。大景别直接切大特写要有明确理由，标为本意跳切。
- 用前景遮挡、反应、道具或声音连接时，说明前镜交出什么、后镜接住什么。声音先入/后留用于画面切点时仍保留完整句所属节点，不据此把一句拆到多个生成节点，也不能用声音掩盖动作未发生。
- 连续长镜头的片段拼接保留同一时间轴、摄像机姿态、焦距、速度和动作相位；不能为生成方便加入新机位。

## 转场进入分镜与逐镜提示词

按 [六类转场编译规范](transitions.md) 选择动作匹配、前景遮挡、形状匹配、甩接、闪白或屏幕拉远机制；普通切镜适合时不强加效果。主表“切点与承接”格写transition_id/类型、叙事联系、是否跳时换场、前镜交出/后镜接住、声音及实际切点或连续揭示区间。前后视频词分别全文列入同镜号提示词表，另列实际剪辑/合成指令与依赖，不把“无缝转场”当成完整生成词。

按机制分别匹配动作相位、遮挡覆盖、目标轮廓、画面流向、白场节奏或屏幕媒体时间；换角度时保世界关系，不能强制所有二维位置相同。屏幕拉远与普通画中画版式区分；持续原片内容需要实际媒体及支持的生成/合成路线。设计、静帧、动态接点、最终剪辑和音轨各自验收，预演图不能证明已剪接成功。

## 风险与资源选择

多人接触、递交物体、精细手部、长时间可辨脸、复杂轨道运动、强连续依赖均提高失败风险。先测试最难镜头；有问题先减少同时发生的任务、缩短可保留时长、拆成可解释的镜头组。用户要求长镜头时先尝试分段同机位续接，不未经说明改成跳切。

关键动作必须有可判读的姿态与接触点。把“害怕”改为“手停在门把前，指尖收紧，目光转向身后”；让演员动作和摄像机共同服务观众任务。
