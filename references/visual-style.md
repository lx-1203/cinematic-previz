# 视觉风格路由与参数锁定

## 入口：先读剧情，再判断是否需要问

工作顺序：**剧情与情绪 → 视觉风格家族 → 参数锁定 → 逐镜分镜与生成提示**。直接使用可执行的视觉语言，不设导演、摄影师或工作室姓名库，不把名字藏在内部路由、选项、参数包或提示词里。职业名称“导演设计”仍表示工作职责。

- 有剧情、场景或既有素材：先读全文，找人物目标、冲突、信息揭示、情绪变化及空间条件，结合用户已经明确的审美偏好直接提出并采用有依据的方案。不再要求用户选择风格、情绪或熟悉电影人物；只把必要假设简短写出，用户可继续修改。
- 剧情短也先判断；“女子开门前听见身后脚步”已足够设计警觉与悬念。不能把缺少精确色号或焦距当成提问理由，也不能只凭类型标签套同一套冷暗调。
- 没有剧情且预期不明时，才问一次观感与情绪，例如：“你希望它看起来是什么样、让观众有什么感受？例如自然温暖、冷峻紧张、明亮轻快，或描述你自己的感觉。”不列人名，不抛技术测验。已有答案直接沿用。
- 剧情与用户的明确风格不同时，先尝试用其风格表达剧情，例如明亮空间同样可以制造悬念；不擅自纠正为类型片惯例。只有真实矛盾使任务无法执行时，问具体冲突，继续独立可做部分。
- 先确定呈现媒介与用途：真人质感、二维、三维、混合媒介；电影/短剧/MV/广告/纪录用途；横竖画幅。已能推断就说明假设后继续，不逐项问卷。媒介、地域、题材和风格分开记录，避免“亚洲=留白”“动画=柔光”的绑定。

## 可扩展的十类检索入口

以下是候选视觉机制，不是互斥的影史分类或“覆盖所有风格”的保证。先选一个主家族，再按叙事选其中必要机制；也可创建水墨、剪纸、定格、像素、复古电视等自定义方案。表中颜色、动作与构图都是可选设计，不是该类型的必备公式。

| 家族 | 可选择的视觉语法 | 适用判断与质量门 |
| --- | --- | --- |
| 透明叙事与古典组织 | 情绪抵达时推近面孔；稳定移动建立纵深；多人物清楚调度与有选择的深焦 | 需要清楚跟随事件与关系。观众先理解情绪和行动，机位变化有信息收益 |
| 黑色与新黑色 | 精确暗调、遮挡窥视；硬阴影切割；有环境依据的大气层次 | 犯罪或道德含混可考虑。暗部保留线索或威胁，不能只把曝光拉低 |
| 心理与诗性观察 | 有情节依据的主观色彩；面孔与停顿；远景、留白和自然时间 | 让人物与环境的关系、沉默有意义；颜色含义由本片建立 |
| 天气、日常与关系空间 | 天气参与调度；色彩与仪式；反射与拖影；高低空间与权力；克制景深；固定日常观察 | 可用于任何文化题材；不强制同用这些机制。去掉台词后仍看得懂关系和位置 |
| 几何秩序与空间压迫 | 单点透视与轴线；对称绘本和平面调度；几何结构与有意偏移 | 建筑线条真正限制或组织人物，不能只把人放在正中 |
| 巨物、史诗与物理尺度 | 环境与人体尺度参照；极简轮廓和大气透视；实体质感；战斗中的速度与停顿对照 | 若叙事需要尺度，大小与距离能被读到；史诗也保留近景和亲密表演，不每镜都缩小人物 |
| 表现主义、哥特与梦境 | 倾斜或变形空间；受控点光；主观阴影；非自然色与现实段落的规则对照 | 扭曲服务心理或世界规则。自然段落有来源逻辑，超现实违背常理须是有意设计 |
| 动画与混合媒介 | 水彩手绘与日常运动；风格化三维与色彩剧本；精细二维天空；纸材、定格或其他自定义材质 | 角色、背景、边缘、材质与动作保持同一媒介逻辑。可借鉴实拍布光思想，再转译为该媒介的结果 |
| 动作与群像调度 | 腾跃与惯性；动作快慢对照；仪式化对峙；静态群像站位后突然爆发 | 空间、重心、视线和动作因果可辨；快速剪辑不能掩盖位置错误 |
| 平台原生与传播用途 | 竖屏纵深与留白；夜间街景对比；暖光生活记录；清楚直接的信息组织 | 小屏、裁切与界面遮挡下主体和文字仍可读；氛围建立时间按实际内容设计，不套固定秒数或滤镜比例 |

## 参数层：把风格拆成能检查的项目

| 维度 | 必须写清 | 防止空话 |
| --- | --- | --- |
| 风格与材质 | 呈现媒介、写实/夸张程度、线条或表面质感、颗粒/锐度、运动形态 | “高级、电影级、某某风”不能代替画面；颗粒与镜头光晕不是必选 |
| 构图与空间 | 画幅；起幅/落幅；主体位置及大小；前中后景职责；视线/运动留白；透视与几何；遮挡/负空间；焦点层次 | 三分、对称或居中须说明作用；消失点随实际几何变化，不能每镜强设中心 |
| 色调 | 整体偏冷/暖/中性；低中高调；亮暗分布与对比；饱和度及高光/暗部处理 | 色调描述整幅关系；低调不等于死黑，高调不等于没有阴影 |
| 配色 | 主色、辅色、强调色分别由哪些物体承载；色相、明度、纯度如何分离；肤色与身份色保护 | 调色不能凭空生出灯具或道具；强调色也可为“本场无独立强调色” |
| 光影 | 既有光源与世界方向、光质、覆盖区、主体背景分离、允许的动态变化 | 与整体调色分开写；固定色温、灯强或45°灯位均不是通用必填 |
| 运动与节奏 | 摄影机运动/固定的动机；人物调度；焦段及画幅假设；焦点；动作触发与停顿/切点 | 不固定所有镜头慢推、广角或高帧率；写数值须区分设计和实测 |

配色可以附少量色块或色号作选材参考，需标为设计参考，不能保证生成视频像素值一致。比例仅在有助于设计时给出，注明估计，不机械套用60/30/10。交付色彩脚本：每个情绪节拍对应“保留什么、改变什么、因何改变”；同一场可以保持同一调色，仅用取景面积、人物进出光区与焦点组织情绪，不必每镜换滤镜。配色层同时检查人与景的分离：人物服装主色与常驻场景主色太接近、明度差不足时，人会糊进背景；强冷暖光下另一色温的服装会明显发暗或发脏，这类问题在配色和光位里改，不靠后期抠像掩盖。

竖屏按目标平台实际安全区域设计头顶、视线与字幕留白；无平台数据时标为规划假设，不能宣称一个固定百分比适配所有界面。手绘、三维均可使用软硬光、反射与色彩对比，依据媒介转译，不把某类灯具绑定某种画风。

## 质感层：胶片、颗粒与光晕是可选项

"风格与材质"一行可以再往下拆五层，用来交代"对了但不像"的那部分：整体色调、饱和度、介质模拟（哪类胶片的色彩与高光行为）、颗粒、高光溢出。五层不是五个必填项；不加介质层完全合法，需要时再写，并说得出年代、媒介或叙事依据。

- 介质与颗粒描述的是画面质感，不替代缺失的主光、构图和动作；写之前先确认这三样已经成立。
- 软化信号要算预算：颗粒、光晕、雾、扩散、柔光最多同时明显两项，其余写成"几乎不可见"或删掉。浅景深再加雾，背景会先糊成一片。
- 颗粒与光晕在部分生成模型里会被放大成可见噪点或糊光；能力未核实时按"几乎不可见"写，或留到后期，不假定提示词已实现。
- 色号、胶片型号、比例都是设计参考，不是接口参数；实际效果以生成后查看为准。

## 反廉价化：通用禁项与题材签名

廉价感主要来自几处固定的东西，与配色无关：塑料感与游戏引擎质感、无意义的对称、畸形或多指的手、数码过锐、没有动机的均匀补光、铺满全屏的雾和光束。有人物时再加一条：蜡质皮肤、磨皮与过度精修。这些在任何题材里都按禁项处理。

反过来，"高饱和、镜头光斑、光晕、大面积欠曝、深阴影"不能一律禁，它们常常正是题材签名。先按片种定放行项，再写禁项：

| 片种倾向 | 可以放行 | 仍要避免 |
| --- | --- | --- |
| 冷峻纪实、正剧 | 低饱和、克制对比 | 失控HDR、广告级鲜艳、为炫技的镜头光效 |
| 科幻史诗 | 去饱和、胶片式高光滚降 | 数码过锐、蓝橙滤镜套路；体积光仍受介质条件约束 |
| 诗意、浪漫 | 柔和光斑、光晕、轻微光学畸变 | 均匀提亮、数码锐利；光斑要有来源 |
| 霓虹、高对比发光 | 高饱和彩色溢光与光晕 | 磨皮美颜、把暗部一律提亮抹平 |
| 恐怖、惊悚 | 大面积欠曝、死黑、低饱和 | 为看清而补光、统一的蓝绿滤镜 |
| 动作、战争、追逐 | 颗粒、深阴影、暖旧调 | 合成感光照、绿幕感；逆光光斑要有真实动机 |

片种表只决定放行与禁止，不规定具体配色：同一场戏的冷暖仍按叙事和既有素材定，不因为片种就通片压蓝或通片刷橙。

## 混合与连续性

一次一个主方案；只有叙事确有需要才借用一个辅方案的1—2个维度。主方案负责至少70%的设计决策，辅方案最多30%，同时列明借入的维度及冲突时服从哪一项。比例描述设计责任，不是可测的像素比例或模型混合滑杆；不要把两套完整体系叠在一起。无需混合时直接用单一方案。

原稿、用户明确风格与已选素材优先。已锁定画幅、轴线、道具、人物和光源不能为风格装饰随意改变。续接沿用实际选中前片的色调、光向和材质；原规划与实际成片不符时先记录差异，不借“统一风格”重画 continue 的真实起帧。重大风格变更另存版本并检查依赖片段。

## 固定六项视觉参数包

在分镜表之前给出以下六项，简短但内容明确。剧情已有依据时由技能直接填写，不把它变成等待用户选择的表单。

| 项 | 内容 |
| --- | --- |
| 1. 风格与情绪 | 媒介、主家族、具体视觉语法；剧情依据；起始→转折→结束情绪；辅方案及借入维度（若有） |
| 2. 构图参数 | 画幅、主体与空间关系、留白/遮挡、透视、景别与焦点倾向；允许的变化 |
| 3. 运镜与节奏 | 跟随/固定/揭示的动机、路径与触发、焦段假设、停顿与剪辑规律 |
| 4. 色调与配色 | 整体冷暖、明暗/对比/饱和度；主/辅/强调色的承载物；肤色保护；节拍间保留/变化 |
| 5. 光影与材质 | 主要光源、方向、光质、明暗层次和变化原因；媒介表面/边缘与材质表现 |
| 6. 提示词与约束 | 把前五项译成可见描述；明确本片硬约束与实际能力限制。支持负向字段才使用，不虚构API参数 |

提示词组织：**主体与状态 + 媒介/材质 + 起落构图与空间 + 动作/运镜/焦点 + 色调与物体配色 + 光源/光质 + 结束状态 + 连续性约束**。首帧写静态关系，视频写动态进程；具体工具字段见 [generation.md](generation.md)。

六项参数包统一全场，逐镜仍要给本镜构图、风格落实、色调/配色与光影变化，不用“同上”掩盖重要信息。表格结构见 [director.md](director.md#默认交付专业分镜表)。

## 交付自查

有剧情是否自行推导方案并说明依据，缺依据才问观感？是否完全去掉用姓名代替设计的路由和提示？风格、色调、配色、构图与光影能否分别指出可见结果？设计是否保留原稿、光源和已选素材？每个镜头的信息与情绪为何这样变化？未预演的比例、焦距、色号与路径是否标为规划？模型效果是否实际查看后才判定？
