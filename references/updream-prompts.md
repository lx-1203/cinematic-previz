# 初始提示词与任务模板

复制一个模板到新聊天，按实际需要替换方括号内容。参数用真实接口返回的 ID；提示词不会自动使尚未加载的 MCP 工具出现，也不隐含授权付费生成。

所有模板都先遵守 SKILL.md 的调用前自更新：按已注册项目运行 sync_from_project.py，成功后重新读取当前 Skill。自更新失败时先报告具体问题，不继续使用旧稿。

## 首次检查插件

```text
使用 $cinematic-previz 里的 Updream MCP 插件说明，检查当前聊天是否能发现 updream 工具。
先运行 diagnose、list_tabs，核对插件连接、版本、已启用画布及实际原生工具。
这里只做只读初始化检查，不修改节点、不提交生成，也不创建用不到的工作区。
如果缺少工具、浏览器未配对或画布未启用，指出具体缺项和下一步；不要假装已连接。
最后给出可用项目/tabId、当前可执行范围和未验证事项。
```

## 每项工作的初始提示词

```text
使用 $cinematic-previz，通过 Updream MCP 插件处理下面这项工作。
目标项目：[项目名称或项目网址]
工作名称：[便于与其他聊天区分的名称]
目标：[具体要修改或创建的节点、预期结果]
生成授权：[不提交生成 / 已授权的生成类型、数量与预算]

先检查连接和真实标签页。只读查询直接执行；需要写入时，为本聊天的这项工作 open_workspace，保存独立 workspaceId，claim_canvas 后再读取并操作节点。
每个写调用带本工作区 ID 与真实 tabId，不复用其他任务的工作区。同项目被占用时先报告占用任务，等待交接；只有上述授权包含其他项目才切换，不用网页点击绕过。
提示词从 get_node 的完整 editDraft.prompt 读取，改名/改提示词优先 checked 更新并核对。多步可用 batch；错误后检查 completed，不重跑整个批次。
操作只覆盖上述目标。模型和参数按当前工具核实，未知结果先查状态，不重复生成；网站确认保留。
执行到目标达成或明确阻塞；结束后释放认领/关闭工作区，报告实际结果和未验证内容。
```

多个聊天并行时，每个聊天各复制一份并填写自己的目标。不同项目可同时执行；同一项目即使换标签页，也需要排队或明确交接。

## 漫剧/视频制作任务

```text
使用 $cinematic-previz，按现有剧本和分镜继续制作。
目标 Updream 项目：[项目名称或网址]
本次范围：[场次/镜头/片段 ID 与要完成的内容]
素材和已选版本：[实际文件、参考图、前段视频与尾帧]
画幅/目标时长：[要求]
生成授权：[已授权范围与预算；未授权则只准备配置]

在需要操作 Updream 时先读 MCP 指南，为本工作建立独立工作区并认领画布，优先使用节点接口；上传、原站确认和未覆盖设置再用界面补充。
保留已有剧本和素材版本。按剧情区分 continue/reangle/cut/reset，超长连续镜头用实际选中片段的真实尾帧续接，不把每个生成片段都当作新机位。
提交前核实实际模型与参数，在已有授权内执行；完成后观看并验收，不把 taskId 或生成完成当成成片通过。
保留生产记录、素材来源与未验证项。收尾释放自己的工作区，交付本次真实完成的成果。
```

## 同项目交接给另一个聊天

原聊天先核对已发出的操作，记录项目、节点/任务与已完成步骤，release_canvas 或 close_workspace。新聊天创建自己的工作区再认领，并读取最新状态；不要仅复制原 workspaceId。

```text
使用 $cinematic-previz 接续以下 Updream 工作。
项目：[项目名称/网址与已确认的 projectId]
已完成：[实际节点 ID、任务 ID、输出版本和验证结果]
剩余：[需要继续的具体步骤]
异常或待核对：[没有则写无；未知结果不能写成失败后重试]
原工作区状态：[已释放 / 原会话已断开，需按指南核对后恢复]

先检查当前真实状态，再为本聊天创建独立工作区并认领；不要沿用旧工作区或重放已完成步骤。仅在已有授权内继续。
```
