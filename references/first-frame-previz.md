# 专业分镜的逐镜首帧白模预演

## 默认交付与用途

本分支在[制作主流程](workflow.md#制作阶段与审核顺序)第5步执行：文档已获用户审核、Excel分镜及所需人物/场景/表情/物品资产已准备后，按镜号批量制作**每个逻辑镜头一张对应起幅的首帧**，实际审图并嵌入核心主表供用户再次审核。主表同时可见四类最终参考和可复用节点/依赖及真实创建状态，原图可从Excel导出或随包取得，不能只交本机路径。按项目已选正式图或白模类型执行；已有合格图直接复用，不强加两套生成。需要白模时使用内置生图生成，不只交提示词；只需文字或无生图能力时按真实范围标缺项。含图Excel未获用户通过前，不进入平台视频制作。

用户未明确要求时不自主生成规划尾帧；表格有尾帧栏、模型支持首尾帧或旧任务曾要求尾帧，均不扩大当前范围。已有合格尾帧可保留历史；生成视频后为已授权接力提取真实出点帧，与另行生图的规划尾帧分开记录。

人物、场地或原有文字缺失时先按[资产缺口自动补齐](generation.md#资产缺口自动补齐)自动查证与补资产，保留原镜头，区分可核实史料与制作推演；不让背影代理阻断已要求的面部近景。

这里的白模图是AI生成的简化体块/黏土模型画面，用来审阅景别、机位、透视、主体比例、前中后景、遮挡、站位和关键动作起态。它不是已建成的三维模型、Blender渲染、深度图、实测灯光或已验证轨迹。不把无Blender当作无法生成静态预演的理由。复杂空间、精确接触或运镜需要验证时，再按 [blender.md](blender.md) 做实际三维预演。

## 生成顺序

1. 读取原稿、最新分镜、角色/空间设定与已有选中素材；沿用画幅、镜号和版本。逐人按 `person_id + variant_id` 解析正确年龄/衣装阶段的当前人物选图、版本和文件/指纹，再按 [表情资产](expression-assets.md) 判断本镜需要生成或复用的神态参考，缺项先补齐或如实标待补。先写一份简短空间基线，再明确每镜**开镜瞬间**的主体姿态、朝向、手别、道具接触、视线目标、可见眼眉嘴线索、互动回应和画外信息。回头尚未发生时不能直接画回头后的落幅；移动揭示镜不能提前完整交出遮挡后的人物。
2. 制作白模时，环境和非必要物体用灰白哑光体块，角色使用完整、连接清楚的人形或符合角色身体形态的模型。关键道具保持可辨轮廓和接触状态，不用乱码、悬浮零件或复杂写实纹理增加负担；制作正式图时沿用已定人物、场景、材质和配色，不把白模外观约束带入。
3. 可给主角或多角色模型统一身份色：同一角色跨镜保持同一颜色，配简短角色映射。颜色之外保留轮廓、服装形状/身高和站位差异，不能只凭颜色确认身份。角色身份色是预演标记，不写回正式服装色或整片调色方案。
4. 在本次已授权生图的范围内，每镜独立生成一张单幅干净图；已有图须逐镜核对新的起态、机位与时代才可复用。人物五视图传身份和衣装，表情图传指定人物的当前神态，场景图与史料原件分别传空间和事实；五视图整版不能直接充当场景首帧，也不能把同一段素材贴成所有子镜的首帧。新切镜须有相应的新观察构图/状态，不能仅改镜号、裁图或镜像冒充；脚本明确回切同一原照时可有意复用并注明理由。镜号、机位、角色图例和运动箭头放在表格/附页，图内不烧字幕、方向字母、工具界面或运动箭头。总览拼版可另附，但不能代替独立单图。
5. 使用内置生图工具的真实输入机制；本地参考先实际查看，再作为附件。准备拟调用参数时，逐项核对人物阶段、表情、场景、物品、构图/状态参考的实际附件、顺序和职责，按 [执行记录只读检查](execution-checks.md) 检查其与选图版本一致后再调用；不能只在提示里写文件路径，不能用别人的脸承担本人物的表情。多参考能力或输入上限不足时标明缺口，在已有工具与授权内选兼容路线，不静默丢掉关键参考。调用后保留真实工具输入和来源版本，核对实际附件确为本次选图。多张图不保证三维一致，换角度不能简单镜像或裁切前图。不得静默切到收费CLI/API或要求用户提供API key。
6. 逐张实际查看并对照分镜：人物身份与阶段、起态、机位方向、景别、主体大小、轴线、手别、接触、角色数量、遮挡、环境结构，以及本景别可读的视线、眼眉嘴和互动回应。左右手从可见掌面、拇指、腕臂连接判断，过肩从人物朝向与头颈肩关系判断，不以提示词写了“右手”或物体位于画面右侧就认证；比例还须结合透视和道具尺度，不能用“特写”掩盖夸大手、断腕或不自然扭身。发现错误，明确变量并在已有授权内针对性修图；表情图合格但首帧僵硬仍属首帧待修，不以“已生成”代替“已核对”。画外或遮挡关系如实列未证，有限尝试失败不等于所有自然机位无解。
7. 选图复制到项目内，例如previs/frames/SH010_start_blockout_v01.png；图片、提示词、生成来源、身份色映射及检查记录按镜号和版本关联。采用不可变版本文件并记录选图SHA；并行写表前重读最新选择，避免同名覆盖使已核证据漂移。将当前完整白模生图提示词直接列入脚本逐镜提示词表，已执行原词与新的重建/修订版分列；保留旧图实际生成词，不把新规划词追称为旧图的执行词。编辑提示附实际编辑目标与版本。通过实际选图更新核心主表首帧与参考列；预演附表仅补充记录，不能代替主表最终选图。Excel导出后核查该行实际嵌入对象及可见像素确为选中版。若经过缩略/转码，保存原图SHA到嵌图指纹的映射并比对实际图像，不拿文件名或已更新路径代替核验，也不要求转码后文件与原图二进制SHA相同。只更新受影响图并保留旧版本。没有真实图像文件时标缺失，不贴占位图冒充产物。

## 首帧的互动、视线与场景表情

本节同时适用于白模预演与正式参考首帧。先从原稿事件、人物关系和本镜目的判断**开镜这一刻**的情绪，再写成可见表演；不默认全程严肃，也不把修正机械变成人人微笑。人物资产只提供身份与服装，资产图的中性脸或严肃脸不自动继承到场景。

有明确表情控制需求时按 [表情资产流程](expression-assets.md) 选择同人同阶段已审通过的图，缺图在已有授权内制作；不能以“已写表情词”或空参考栏代替实际表情输入。无独立表情图时保存剧情/可见性/复用或真实续接理由，能力不足保持待补。表情参考里的头向和眼线只供该图的神态辨读，首帧中仍按场景实际对象重新确定。

- **逐人落地**：写明每人看向具体谁或何物、头部与身体朝向，以及景别能读到的眼眉嘴线索；不要只写“自然表情”“有交流感”。同一场景中的两人可以有不同反应，幅度依据当前事件与角色性格。
- **建立互动因果**：明确谁发起、对方在本帧已有的可见回应，或两人关注的同一目标。递物时写清物件位置、持物者和接触/待接状态，朝向、视线与手势应指向同一次交流，避免两人无缘由各自低头。互动不等于必须对视；共同研究看物、回避目光或冲突中的错开视线，应有剧情依据和可读身体回应。
- **只画当前起态**：静帧只描述本时刻，后续转头、接过物件或笑容展开仍留给视频；不能为了互动把尚未发生的完成动作提前画进首帧。已有真实续接起点仍遵守下节，不重画替换。
- **按可见性验收**：实际查看眼线是否落在指定对象、双方姿态和手势是否构成互动、脸部是否呈现本场所需表情。脸在画外、被挡住或白模无可辨五官时，表情记为未验证，仅验可读的布局与动作，正式图再验脸；不能靠提示词或文件存在判通过。
- **针对偏差修正**：出现固定严肃脸、无依据的笑容、视线错位或只有发起者没有回应时，按实际问题修改表情/朝向/接触等对应变量，在已有范围内修图并重审。用户仅要求首帧时保留尾帧，不顺带扩展生成。

## 起幅与接力约束

多人首帧与额外关键帧按[多人调度与危机反应](performance-compiler.md#多人调度与危机反应)核对不同人物的姿态、朝向、视线、手部/持物与动作相位；危机场景还要在本镜开镜时刻读得出相应压力，不能用整齐列队或平静合影替代原定反应。

首帧必须是本镜动作开始时的可见状态，不用本镜最精彩的落幅冒充起幅。需要审阅揭示或复杂姿态变化时另做关键帧，标为中间/落幅，不能替代首帧。角色在画外、手被挡住或面部不可辨时如实记录，不靠另一张图“推断已通过”。

- 前期只有剧本时，白模图标为planned的首帧规划；没有视频就没有真实尾帧，不虚构接力证据。
- 已有成片的continue沿用上一选中片段的真实出点帧。预演表可直接展示这张实际帧，**不为了统一灰白外观重新生图替换续接起点**。逻辑镜头的工具分段不额外制造新镜头首帧。
- reangle有实际前片时，以其真实末态提供人物/道具状态，新机位负责构图；没有真实前片时只交规划版，不能声称状态已经冻结在实际成片。
- 白模身份色不能污染后续正式图。进入外观制作时明确白模只传构图/布局，角色/服装/色调来自正式资产与视觉方案；若工具无法分离参考职责，记录限制并选兼容路线。首帧制作与视频输入见 [generation.md](generation.md)。

## 高级运动的关键帧职责

高级镜头按 [camera-language.md](camera-language.md) 选检查点。普通镜头按设计开镜状态审起幅，不随意用甩镜中过渡帧、移焦后的清晰对象或拉远后的全景偷换首帧；有意以遮挡/模糊/白场入镜的转场按下节分别标记布局与实际入点。为审阅揭示、复杂绕行和升高，可另做标明角色的中间/落幅规划图；整周需关注沿途地标与人物侧背面，上升需关注高处结构与障碍，不能只让首尾相同就判路径通过。

每张额外关键帧按镜号、版本、规划时间和职责关联，独立审图也不证明帧间连续运动。精确路径/焦距/遮挡验证使用实际三维或动态预演；移焦、速度变化、慢动作与音画节拍需看实际运动结果。仅更新技能规则的请求不自动触发示范生图或视频收费试验。

## 转场入点与清楚布局分开

按 [transitions.md](transitions.md) 标记前出点、后入点、匹配锚点和时间/空间断点。实际剪辑入点可能全遮挡、模糊或白场；另做清楚布局/可见状态规划帧时标frame_role=layout或相应关键时刻，不冒充实际开镜图、真实尾帧或速度证据。原生成片段的预留余量起点也不一定是最终剪辑入点，文件/时间分别关联。

形状匹配审目标轮廓、占幅与朝向；甩接审沿途流向，静帧只能看布局；屏幕拉远审边框/外层环境布局，屏内原视频另作媒体，截图不能证明继续播放。continue仍不重画实际起点；reset按B布局和资产准备，不能只拿无信息A尾帧推断新场。规则更新中的文字示例不自动要求生成演示图。

## 提示模板与检查记录

**提示组织：** 当前已选白模/正式图类型 + 每个角色的具体阶段与人物参考职责 + 所需表情参考及其对应人物 + 已知空间结构 + 本镜画幅/机位/景别 + 开镜姿态/头身朝向/视线目标 + 可见眼眉嘴线索与幅度 + 人物间本刻已发生的发起/回应 + 前中后景与遮挡 + 关键道具/手别 + 必须保持的连续性。白模另明确简化灰白黏土、角色身份色与造型映射；正式图使用已定服装、材质和配色。逐镜展开成完整正文，不能只保留模板词或写“自然表情”。只画本次机位的一幅画面，不画多格故事、俯视布景图或软件截图。光线以可读形体为先；若展示既定光向也标为生图示意，不宣称验证照度/阴影。

记录最少包含shot_id、script_version、frame_role=start、实际source_kind（白模生图可用codex_imagegen_blockout，正式图按真实来源）、文件/指纹、每人person_id/variant_id、人物与表情选版/职责、无独立表情图的具体原因、原始提示、拟调用与真实输入附件、白模身份色映射、实际目视结果、需修复项及未验证项；并入现有制作登记，不另建第二台账。人物/表情选版改动时复核受影响首帧、视频与主表，保留实际历史调用。SHA和像素一致只证明素材绑定，几何阈值或错误计数归零也不证明人体自然、取景有叙事作用或“电影级”通过。构图图没有证明运动、焦点转移、说话时长、角色表演或色调/打光已经在视频里成立；动态像素变化或移焦更不能代替人物戏，实际片段仍需完整正常速度回放，相关检查分开记录。
