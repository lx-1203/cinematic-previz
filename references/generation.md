# 首帧与视频生成适配

连续有声短片的发声覆盖、实际成片偏差与多参考分工，另见 [ai-video-continuity.md](ai-video-continuity.md)。使用 Updream 时先读 [updream-mcp.md](updream-mcp.md)；本地上传、原站确认和未覆盖参数再读 [updream-ui.md](updream-ui.md)。插件只操作已暴露的 canvas/gen 能力，不能把本地文件路径当作已上传素材，也不能虚构音频、角色库或首尾帧参数。

## 生图输入的职责

实际查看本地图片后，再按当前工具参数附上图片。绝不能只把文件路径写进提示词当作图片已经传入。优先内置 `image_gen`，不需要用户为此提供 API key；不静默切换到收费 CLI/API。

| 模式 | 构图来源 | 状态来源 | 外观来源 |
|---|---|---|---|
| 首镜/独立镜头 | 对应 Blender 摄影机图 | 剧本与已确认场景 | 固定角色/场景参考 |
| reangle | 新摄影机白模图 | 前镜真实尾帧、末段动作 | 固定参考持续参与 |
| continue | 直接复用前段尾帧 | 前段尾帧和末段运动 | 尾帧已包含，不重新生图 |
| reset | 新场景机位图 | 新时间/空间设定 | 延续所需身份与画风 |

工具支持本地引用路径时用真实路径参数；支持最近对话图片时使用最少但覆盖全部目标的图片数。遵守当前工具说明，不同时使用互斥引用方式。生成后把最终选图复制到当前项目并保存版本，不能只留在全局生图输出目录。

构图和身份参考是引导，不是像素或几何锁定保证。必须实际查看生成图，检查脸、服装、道具、手别、画面占比、地平线、遮挡和新机位。多格分镜表仅供制作审阅，普通图生视频的主输入应是单幅干净画面。

## 先探测视频能力

从已连接工具的当前 schema 或官方文档记录下表；无法确认用 `null`，不能猜成 `true`。只有在准备实际调用时才需要在线核对，能力缓存注明模型 ID 与日期。

| 能力 | 决定 |
|---|---|
| 单首帧 image-to-video | 能否以已选首帧驱动片段 |
| 首尾双帧 | 能否提供计划终态；支持才写对应字段 |
| 参考视频及其参考用途 | Blender 片段可否传递运动/布局 |
| 扩展/续写 | 是否能读取前片的运动历史 |
| 最大/可选时长、画幅、分辨率、帧率 | 逻辑镜头如何分段与交付 |
| 输入互斥、数量/大小、音频/对白支持 | 如何打包素材与后期声音 |
| 价格、额度、返回任务/下载方式 | 已有授权是否覆盖本次请求及重试 |

没有连接可用视频工具时继续准备镜头、图片、提示、引导片与交接清单，明确 `blocked` 和缺少的能力。不要创建假 job ID，也不要假称已提交。

## 路线选择

**只支持首帧：** 用干净首帧和简洁动作提示。Blender 视频用于人工/视觉比对，不能声称相机路径被硬控制。`continue` 可直接用尾帧续接，接点需要更严格验证。

**支持首尾双帧：** 起点和终点都要符合动作与空间，中间路径仍需检查。目标尾帧是规划输入，生成视频真实尾帧是实际输出，二者不能混用。

**支持参考视频：** 导入生成引导版，明确只继承位置/运动/布局。角色、画风和首帧的职责分开；若模型不支持视频与首帧同时输入，按实际可用路线选择：视频加外观参考，或首帧路线。不能伪装成所有输入都生效。

**仅采用风格板的路线：** 用多角度人物、环境、道具参考传递外观，避免某张图的构图与运动片冲突。它不是所有平台的默认，也不是干净首帧的替代参数；逐模型核对。

**支持原生扩展：** 可利用运动历史；记录扩展来源和实际新增时长。用户要求尾帧续接时，先遵循明确要求，能力更合适的替代路线说明清楚。

## 每片段提示的内容

写一个主动作、一个主摄影机行为及明确终态。时间分段只用于确有阶段的动作，不把多镜头、多人精细交互和多种运镜塞进一次生成。环境运动服务剧情。

`首帧已确定的状态 → 此段继续发生的可见动作 → 摄影机行为 → 此段终态 → 需要保留的身份/空间约束 → 针对实际风险的限制`

同机位续接的下一段不要重复“走进房间”等已完成动作。接正在发生的动作时写其剩余部分；摄像机到达中途而非轨迹起点。画外台词、声音与字幕只有工具支持才放在生成请求，其余由剪辑阶段处理。

## 检查、修复和交付

- 生成前：首帧正确、动作可行、能力与参数成立、授权范围清楚。
- 单段后：观看完整片段，并看首中尾和接触帧；确认动作真的发生，而非仅摄像机漂移。
- 接点后：前尾/后首并排，加前后各一小段正常速度回放；静态图相似不证明速度或动作连续。
- 整场后：镜头目的、节奏、视线、空间与声音关系可读。

脸/服装问题优先回首帧或原始参考；路径和接触问题回白模；片段边界动作重置回全局时序/动作描述；工具不支持的控制回路线选择。每次修改一个主要变量，记录实际结果。在已有授权内可针对性重试两轮，仍不成立则改变镜头方案或明确阻塞。

最终交付可编辑 `.blend`、选中图片/片段、逻辑镜头合成、最终剪辑、制作清单与未验证项，按用户范围缩减。开源 skill 不意味着底层生成服务免费，也不意味着已连接某厂商账户。
