# 尾帧、换机位和超长镜头续接

## 交接源的真实性

交接依据是选中版本在**实际剪辑出点**的最后显示帧。不要按“总时长减一点”盲取，不拿脚本预计状态或最初首帧替代。先确认版本、裁剪范围、速度变化和是否有黑场/变形。

如果最后画面坏了，先选更早的候选帧，再把前片出点裁到该位置，确认对话和动作仍完整；从最终保留片段重新提取。不能保留视频更晚的动作，再接回更早帧造成回跳。无法获得源视频时可以按脚本做规划候选，但状态为 `planned`，不可称为真实尾帧接力。

提取工具：

```powershell
python "<skill-dir>/scripts/frame_bridge.py" extract "<project>/clips/SH010_SG01_selected.mp4" --out "<project>/handoffs/SH010_SG01_tail_v01.png"
```

它解码计数再精确选帧，不依赖容器声称的帧数或平均帧率。输出 PNG 与同名 JSON；JSON 保留帧编号、时间、源视频/图片 SHA-256。人眼检查后，在 `production.json` 记录该凭据路径、当前选中源和检查结果。`verify` 只检查来源指纹，不为叙事连续性背书。

## 先冻结状态，再选择视点

查看尾帧及必要的末段运动，记录：角色身份/服装、世界位置和朝向、视线目标、手别和持物、物品接触/附着状态、动作阶段、表情、时间天气、光源方向、背景地标。实际视频和脚本不一致时先处理差异，不自行假定已经达到脚本终态。

以尾帧恢复状态，场景和角色设定补全画外部分，Blender 提供新视点的空间约束。原始身份参考持续参与；每小节核对固定设定，避免只靠上一张图层层传递导致累积变脸。

## continue：一个长镜头，分多次生成

1. 先核对目标模型实际单次上限和可选时长。例：逻辑镜头 18 秒、工具最多 6 秒，可以规划 3 个片段；这是示例，不是写死的模型参数。
2. 给全部片段同一 `shot_id`，各自 `segment_id` 和逻辑镜头内全局时间。导演意图、摄影机路径、主体动作仍是一镜。
3. 生成并选出第一段，提取真实出点尾帧。**该 PNG 原样作为下一段首帧，不调用生图换角度、不修脸、不重新构图。**复制文件时保持图像指纹一致。
4. 续段提示描述“从此刻继续”的动作和下一阶段终态，不重演上段动作。结合末段视频估计人物、摄像机的运动方向、速度及变焦趋势；一张静态尾帧本身不包含速度。
5. Blender 引导片采用同一全局曲线的下一段，不在片段边界重新缓入缓出。若平台有实际可用的延长功能，可在用户目标内选择，但记录它的控制方式，不能声称普通首帧输入等同于完整视频扩展。
6. 回放接点前后，检查大小、焦距感、背景、身份、动作相位、速度和音频。模型产生重复首帧可剪除重复帧；动作重演或速度突变需要重做/调整，交叉溶解不能代替修正。

提示模板：

> 输入图就是前段最后保留画面，直接从这一时刻继续同一个连续镜头。人物此刻已完成【已发生动作】，继续【尚未完成动作】，结束于【下一状态】。摄影机保持【机位、方向、运动与速度趋势】，无切镜、无重新构图、无动作重置。保持角色、持物手、地标和光向一致。

普通首帧图生视频可能无法保住运动导数或复杂变焦，必须标注实测结果。优先通过支持的扩展/运动参考减少跳变；连续失败就报告约束并提出可选剪辑，不假称无缝。

## reangle：有动机的新机位切镜

1. 明确为何换角度：揭示表情、接触细节、另一人的反应或隐藏空间；切镜不是每节固定动作。
2. 用前镜尾状态冻结 Blender 场景，移动**摄影机**建立下一镜。不要通过旋转角色或移动道具伪造视点变化。改变机位会自然改变画面左右与遮挡，按世界状态和轴线检查。
3. 三类图片分别传入：前镜真实尾帧负责当前状态；下一机位白模图负责构图；原始人物/场景参考负责外观和新露出的区域。不可见部分只能由设定或合理推断补全，不称为从单图恢复的真实三维。
4. 生成同一动作阶段的新角度首帧。不是水平翻转、裁剪或简单放大；这些操作无法露出物体新侧面。
5. 比较交接两图及俯视图：手别、持物、动作阶段、视线、光向和空间关系是否成立。新首帧不得提前完成下一动作。
6. 从通过检查的新首帧生成下一镜，再验证剪辑接点。

提示模板：

> 图1是上一镜实际尾帧，仅提供当前人物与物体状态；图2是下一镜 Blender 机位图，提供摄影机视角与空间布局；图3起为固定人物/场景参考。生成与图1**同一时刻**的新机位首帧，采用图2的观察方向。保持【世界状态、动作阶段、手别、道具、身份、光源】。只改变观察视点及其自然产生的透视与遮挡，不推进时间、不镜像人物。

## cut / reset 与改版

反应镜、插入镜和视线切可直接从设定与白模生成目标首帧，尾帧只提供相关状态；换场跳时则声明时间/空间断点。不要为了统一流程强迫每镜都改前尾帧。

每个依赖边记录：源片段版本及指纹、尾帧凭据、衔接方式、下一首帧版本、依赖理由与复核状态。替换源片后，立即标记依赖首帧及后续视频为 `stale` 并沿依赖继续检查；无关分支保留。确认状态不受影响后可重新关联新来源并记录复核，不必机械重生全部影片。
