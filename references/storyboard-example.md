# 走廊回望｜专业分镜表 v1

夜／内景／15秒／4个逻辑镜头／16:9。以下为文字设计方案，焦距按全画幅假设，秒点与构图需预演验证。

原稿：女子右手持钥匙走向走廊北端的门。正要插钥匙时，南端传来脚步，她停手回望，看见一个静止的人影。

场次基线：西侧窗只有微弱外部夜间环境光，北门上方只有一盏稳定暖灯。全部机位在人物关系轴东侧；灯位、曝光与白平衡保持连续。钥匙全程在右手，未入锁，门始终关闭。远处浅墙和衣服反差作为明确的美术规划假设，未测光，不增加光源。

视觉递进：跟随接近 → 动作骤停 → 目光转移 → 空间揭示。

执行核对：4＋2＋3＋6＝15秒；抬手、停手、回头各发生一次；SH030→SH040为同一时刻的视线切镜，起幅肩线遮挡及横移揭示需试位，不视为已验证轨迹。机位不得穿过北门。若远处轮廓不够清楚，先调整既有光下的背景/服装反差与站位，不补造光源。
