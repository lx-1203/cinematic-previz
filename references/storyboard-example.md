# 走廊回望｜专业分镜表 v2

夜／内景／15秒／4个逻辑镜头／16:9。本文为文字设计，焦距按全画幅假设；站位、秒点、取景与光效需预演和实际画面验证。

原稿：女子右手持钥匙走向走廊北端的门。正要插钥匙时，南端传来脚步，她停手回望，看见一个静止的人影。

## 从剧情判断视觉方案

情绪走向：接近门的短暂放松 → 动作被打断的警觉 → 转身寻找声源 → 确认有人后的持续不安。观众先贴着女子行动，最后才看见她看到的对象。本场采用克制的写实悬疑，借有限视野、动作停顿和纵深揭示组织紧张，不新增超自然事件或装饰光效。剧情足够支撑此方案，无需让用户另选风格。
