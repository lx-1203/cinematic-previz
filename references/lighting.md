# 打光语言：用明暗组织叙事

这份规约服务分镜、首帧与动态生成，不把打光简化为风格形容词。先说明观众应该注意谁、什么暂时看不清、何时发生可见变化，再选择光线。电影感不等于压黑、强轮廓光或固定冷暖配色；明亮、平坦、柔和也可以有明确叙事作用。

## 先建立场次光线基线

沿用原剧本的时间、天气、空间与已选素材。记录主要光源来自哪里（窗、天空、场内灯具、火焰等）、世界方向/高度、覆盖区与遮挡物、主次明暗、色彩关系及允许变化的原因。未知区域标为设计假设，不为炫光新增窗户、灯具、超自然发光或改变日夜。

换机位时光源留在世界中的原位置，重新判断它在画面中的方向；不要每镜都重新写“左上方主光”。允许为造型作有动机的调整，但不能让同一时刻人物阴影、地面投影和亮暗侧互相矛盾。已有选中成片先读取实际光线，计划中的基线不能冒充实际结果。

## 每镜选择什么、为什么

| 设计项 | 写进镜头的可见结果 |
| --- | --- |
| 主光与来源 | 哪个方向的什么光建立脸/兽形/道具的体积，观众为何先注意这里；光源可在画外，但要有空间依据 |
| 补光或负补光 | 暗部需要读到多少；负补光是减少反射补光、加深指定暗侧，不是另加一道黑色灯光 |
| 光质与阴影 | 需要清楚边界还是柔和过渡，阴影落在哪里；光的软硬与主体所见的有效发光面积及距离有关，不能仅凭灯更亮或更暗来判断 |
| 明暗层次与注意力 | 主体、前景、背景哪些保留细节、哪些弱化；不让无关亮点抢走关键表演，也不为照亮脸而把空间全部补平 |
| 轮廓与背景分离 | 是否需要用边缘亮度、背景明暗或颜色区分人物；轮廓光不是每镜必配，剪影也须保证动作和形状可读 |
| 光色与环境 | 光源之间的相对冷暖、服装/肤色/毛色与环境如何相处；结合白平衡和整体画风，不把蓝色固定等同悲伤、暖色固定等同安全 |
| 动态与叙事节拍 | 人物穿越光区、真实遮挡、转身或已有光源变化在哪个动作点改变可见面；稳定光线则交代人物表演如何在同一光下被读到 |

每镜继承场次基线，只写有辨识度的光线结果与变化，不重复整份灯位表。对比度可以描述为“眼眶暗部仍可读、背景比侧脸弱”；光比、色温、曝光或灯强只有在有明确设定、参考或测量依据时写数值，并标明是规划还是验证值。

## 光线怎样随镜头讲故事

先确定信息的出现顺序，再安排光和遮挡。例如人物经过已有灯下时，先让手中线索短暂可见，再用侧脸表情承接；或者让人物离开明区而背景关系仍清楚，用同一空间中的亮暗变化表达距离。示例是设计机制，不是强制套用的镜头顺序。

镜头移动前检查整条路径：摄影机能否一直看见关键动作，人物转向后亮暗面如何改变，前景遮挡会不会把关键证据完全盖住。需要隐藏身份时可保留轮廓或局部细节，但不能同时要求脸完全不可见与清晰辨认微表情。

雾、尘与可见光束只在剧本、美术与空间条件允许时使用，不能每场自动加体积光。调色负责整体色彩与对比的整理，不能替代缺失的主光方向、错乱的投影或本来就看不清的动作。

## 生图、预演与验收

- 首帧提示写出场景光源、方向、光质、明暗关注点与颜色关系；镜头运动提示写出这些关系随人物/摄影机移动怎样保持或变化。不能只附加“cinematic lighting”。
- 起幅、信息揭示点与落幅核对人物亮暗侧、阴影、背景层次和注意力，关键转折可额外准备光线关键帧；不要与大量文字规范帧混为同一种职责。
- 灰模/Workbench能验证几何和遮挡，不能证明实际打光。需验证灯位时按 [blender.md](blender.md) 用实际光照渲染模式另做光照草测；没有渲染或没有实际查看时标未验证，不伪造图像/测光结果。
- 回放检查亮度是否无故跳变、主光是否随摄影机漂移、阴影是否与动作一致、白平衡是否跨接点突然变化；主体、文字与关键接触是否仍可读。模型漂移先按对应变量修复，沿用已有预算、授权与重试边界。
