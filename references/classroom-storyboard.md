# 课堂补充：情境分镜、镜头索引与连贯性

根据用户补充的14张课堂照片整理，作为可按剧情选用的方法库，不是历史事实来源、平台能力说明或新的强制模板。下表是机制归纳，不是逐字课件转录；照片第51、52项标题较模糊，保留编号并用可辨描述检索，不猜定原名。

## 使用边界与原有流程

先执行[朗读核算与15秒大段规划](timing.md#先核算朗读再排15秒大段)，再在每个multi_shot包内设计小镜头。课件的单镜秒数、镜数和剧情占比仅作内部节奏参考，不恢复为每小镜独立生成，不改变主表一包一行、[提示词指导分表](director.md#默认交付专业分镜表)及[完整正文格式](prompts.md#提示词正文交付检查)。

查镜头术语时，先选本镜新增的信息、关系或情绪，再查下表；需要具体实现时只读对应的[摄影公共规则和方法](camera-language.md)。不要求每片用齐60种，不规定必须运动，也不用术语替代完整画面描述。没有实际视频时仅能完成设计检查，不能宣称动态连贯或人物一致已经通过。

## 六类情境写法

每镜先确定观察任务，再把主体与当前状态、可见动作、空间关系、景别与机位、运动或固定、焦点、光线和声音写进原有正文。下列片段仅展示写法，不能直接冒充完整生成词；实际素材引用、分阶段镜头和阶段音效仍按prompts展开。

| 情境 | 应写清什么 | 局部写法示例与切镜依据 |
| --- | --- | --- |
| 开场与登场 | 地点锚点、进入路线、减速或停步、注意目标 | 中景侧跟人物沿书架走向柜台，脚步放慢，目光落到信封；前景书脊掠过。登场、到达、发现是否拆镜取决于观察任务，不能只靠一段笼统“走过去”。 |
| 情绪与反应 | 情绪的可见证据、触发、幅度、结果 | 近景中手伸到一半停住，指尖收回，眉间轻皱、嘴唇抿紧；摄影机轻推到脸部。动作成立才表达犹豫，不能只写“她很紧张”。 |
| 对话与关系 | 人物左右及前后层次、说者/听者、视线、轴线、焦点 | 左前景为对方肩膀，右侧主角面对对方先点头再皱眉；本镜主角是听者，嘴唇闭合，焦点在眼睛。换反打要对应视线，不把所有人物都写成同时闭嘴又说话。 |
| 动作与细节 | 拿取、行走、停步的起态、手别、接触与完成状态 | 人物停在门前，身体保持原位，右手缓握门把；侧后固定拍摄，门缝透暖光。手握门把与拧开门可分观察任务，不能每个动词机械新增任务或漏掉接触。 |
| 悬念与发现 | 谁先看见什么、遮挡与揭示次序、清晰层、停止位置 | 全景中人物站在店内；门外磨砂玻璃出现人影，缓慢靠近后停住，机位固定，室内暖光与门外冷光区分层次。未揭示者继续藏住，不能提前清楚露脸。 |
| 收尾与转场 | 当前动作完成、离画或留画、落幅与余音、下一镜承接 | 信封放入抽屉后人物坐回椅子，摄影机后退露出书架和空过道，坐姿保持。人物离画、形状呼应或拉远按故事选择；结尾不默认加黑场、片尾卡或新事件。 |

以上动作、光线和书店只是教学示例。历史题材改用已核实的时代、人物阶段及物件，不把示例信封、悬念或心理活动编成金善宝的史实。情绪表达、摄影复杂度和镜数服从原稿，不为“更戏剧化”虚构失败、对抗或危险。

## 60项镜头检索

编号沿用课件顺序。近义名称可以共用机制；“适配”表示候选叙事作用，不规定某种情节只能用某种镜头。M编号指向camera-language中的既有方法；不带M编号的项仍按摄影公共字段展开。

## 节奏与立意：条件使用

**秒数先于镜数，朗读先于秒数分配。** 完整旁白/对白按真实文字和所选读法先核算，再安排动作、停顿、转场与结尾。包数按15秒大段与实际工具能力规划；内部镜数可用“实际分配秒数÷适合本段的平均镜长”估算，最后仍要检查事件与声音能否完整发生。

课件的2—3秒动作切换、3—5秒常规观察、5—8秒情绪停留可作快慢对照；另一页的“3—8秒硬约束”不升格为本技能硬限制。1—3秒的有效插入镜、必要的长镜头都可成立；长镜需持续有注意变化，短镜需看清目标。不能按2—3/3—5/5—8的三五二比例机械配额，也不能把3分钟约60镜换算成60次生成。

“开场20秒、铺垫50秒、冲突70秒、收尾40秒＝180秒”只是课件的3分钟剧情案例。“冲突近四成”及各时长建议镜数也不是所有片种的指标。可借用建立处境→展开关系→推进难题→给出结果的结构，但纪实、科教及历史人物片按事实和已审原稿组织，不制造“两次接近失败”或追剧钩子；不为满足例子扩写到3分钟。

主题候选可从对比（宏观/微观、过去/现在、理想/现实、不同人生阶段）、共鸣（生活细节、职业、时代处境）或追问（选择、价值、生命意义）中挑一条，再落到可见事件。历史对照须区分已核事实、设计隐喻和未知部分。课件按国家列举的广告/编剧/特效/动画/色彩/历史案例，只作寻找具体表达机制的灵感线索，不把国别刻板印象、创作者姓名或照搬作品桥段当风格方案。

## 角色资产版式的兼容

课件展示“左1/3面部特写，右2/3正面、标准侧面、背面三张全身图”的横版角色板，可在用户明确选用此版式时采用；它不取代当前[双参考五视图完整模板](character-assets.md#人物资产生成完整提示词)，不因此重做或改裁已审资产。

可复用的质量目标：纯净白背景、同一人物和阶段、清楚的面部/发型/材质、三张身体视图同尺度对齐、鞋底完整、无透视畸变、无磨皮或身份漂移。面部特写与全身图本就尺度不同；不同角度的可见褶皱也会不同，不能要求像素位置完全相同。写实皮肤目标仅用于既定写实项目，动画或其他风格沿用本片方案。中性资产不替代逐镜表情和行动，实际审图后才可标合格，“100%一致”不能当生成保证。

## 连贯性：生成参考与成片时间分开

视频延续、动作重叠与故事板都是候选方法，不是任一工具都支持的功能。按[实际出点与任务间交接](frame-handoff.md)确定来源和模式，正常速度观看接点及试听后才能判断效果；首尾图相近不证明运动、表演或声音一致。

- **视频延续参考：** 工具实际支持视频输入/延长时，可取上段选定版本实际出点之前的末段运动作上下文；课件“末3秒”是候选长度，按能力、动作和预算选，不盲取文件尾部。记录源版本、出点、上下文范围与输入职责，遵守continue真实尾帧规则，不将普通首帧输入冒称视频扩展。
- **动作重叠素材：** 仅在明确选用额外重叠素材的路线时，为剪辑准备上下文或前滚，并记录两段源时间对应；这不是continue的默认开场。成片在同一动作相位只保留一次，删掉重叠区再按实际保留帧建立后续依赖，不能让人物重复伸手、拿放或回到过去。原包15秒输出预算、额外生成成本、剪辑保留时长及完整朗读分别核算，不能把重叠时长重复计入成片。
- **小剧情故事板：** 包内先建立、动作、反应或揭示再落幅，让每段有可读进展；课件5—8秒小剧情是可选节奏，不重新拆成默认独立任务，不把多个故事节点挤进放不下的时间。
- **删镜与转场修复：** 可在授权范围内选择更好的切点、删冗余或有动机转场；先保全完整旁白、必要动作和关键事实。不能用模糊、叠化掩盖人物漂移、接触错误、剧情缺失或动作回跳，并将其记为连贯性通过。源片改版仍沿依赖标stale并复查。

交付前的专项语义检查：六类写法是否服务当前剧情；选用术语是否落实成真实路径/焦点/表演；课件示例是否误变成硬参数；朗读、15秒分包、提示词分层与Excel分表是否仍一致；人物资产默认模板是否被误换；重叠素材是否已从成片去重。检查结果写入现有审阅记录，不增主表列。
