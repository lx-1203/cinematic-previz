# Skill 可视化查看器

本机页面直接读取当前skill文件和module-index，展示安装与来源状态、规则读取顺序、更新记录及原文。它是查看器，不替代调用前的同步门禁，也不自动修改规则、上传GitHub或启动媒体生成。

## 启动与查看

Windows双击技能目录中的[start-dashboard.bat](../start-dashboard.bat)，或运行：

```text
python "<skill-dir>/scripts/skill_dashboard.py" --open
```

需要Python 3.10及以上，无第三方运行库。服务仅监听127.0.0.1，默认端口8769；相同skill已有服务时复用，其他服务占端口则选空闲端口并输出实际URL。AI在Codex里交付时，读启动输出的URL并在右侧浏览器面板打开；不要把源码路径或猜测的端口当预览地址。关闭运行服务的终端或按Ctrl+C停止；复用已有服务时关闭新开的启动窗口不会停止原服务。

可用`--skill-dir`选择另一个兼容模块索引的skill目录，`--port`指定首选端口。使用注册安装目录才能显示与其来源的同步比较；查看开发工作树时其本身可能是独立目录，不能据此声称当前安装已同步。

## 四个页面

- **总览：** 当前内容版本、内容指纹、本机同步状态、GitHub核验时间、文件数和最新更新。版本号保持不变也可能有内容更新；指纹及实际文件差异才是判断依据。
- **读取路径：** 选择任务预设或可读模块，直接调用既有read_modules解析共享规则、父节点和requires依赖。步骤顺序与读取器输出一致，节点显示具体文件、选中章节及原文。分类树和执行依赖分开，不自动展开全部兄弟方法。同步门禁与SKILL入口另行显示。
- **更新记录：** 读取实际CHANGELOG标题与正文，按文件顺序展示。历史条目是变更记录，现行规则仍以对应正式来源为准；日期不是某个媒体项目已完成的证据。
- **规则文件：** 搜索包内公开文本，查看原文、预览、文件修改时间和SHA256。模块节点可能只加载文件的指定章节，不把“查看整个文件”等同于读取器已加载整文件。

页面显示的是**当前规则解析出的阅读顺序**，不是AI历史阅读日志，也不是模型内部思考。未记录的过去会话阅读不能从模块图推定。需要历史审计时应另有明确的调用记录来源，不能凭可视化节点自动标成“AI已阅读”。

## 本机与远端分别核验

本机状态每次刷新重新计算，页面每15秒自动刷新；已打开的原文保留本次查看内容，重开或刷新查看最新文件。`current`表示注册来源、安装内容和登记指纹一致；`needs_sync`表示内容有差异；`metadata_stale`表示内容一致但登记指纹过期；来源缺失或损坏显示error，不退回standalone掩盖故障。无来源登记才显示standalone。

GitHub默认为“未核验”。点击核验才读取注册来源的Git origin/main并正常fetch，只更新Git对象/远端跟踪引用，不改工作文件、不提交、不推送。按远端树blob与当前来源内容逐项比较，区分完全一致、有差异、失败和结果过期；同时记录commit、检查时间、差异路径及所依据的内容指纹。仅获取最新commit不算内容一致。源文件后续变化会使旧核验结果失效，页面不能继续显示当前内容已备份。

核验结果缓存于安装目录的`.local/dashboard`，不纳入skill指纹、同步或公开备份。网络或Git登录失败仍可查看本机文件；核验错误不自动执行登录、读取凭据或启动无限重试。其他仓库/分支结构需按实际维护配置适配，本界面当前核验origin/main，不猜测其他发布目标。

## 验证范围

原文、依赖及更新状态来自实际文件和读取器；界面可用不代表规则语义、具体人物资产、动态视频或音画已经验收。仍沿用[模块读取](module-loading.md)、[维护收尾](maintenance-release.md)及当前任务的专项检查。
