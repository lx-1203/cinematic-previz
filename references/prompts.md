# 提示词编写与原词执行

按触发条件使用本文件：写/改视频词读格式、骨架与交付检查；提交生成再核对原词来源与工具能力；制作资产/首帧、表演或跨段续接时才用对应细则。文字草稿按当前范围交付，不因写词自动制作文档、Excel、图片或视频。[生成适配](generation.md)负责实际附件和工具能力。

## 提示词的区块、编号与素材引用

视频词保持“全局设定→角色场景→比例与状态约束→分阶段多镜头及音效→结尾”的既定格式。每个15秒multi_shot包可独立复制；包内只写本镜必要变化，不重复整段背景、材质和全部禁项。精简说明，不省略关键动作、台词、引用、光向、切点或验收所需信息。

### 全片正文的层次与密度

1. 开头写整体视频风格设定、光源设定、光影系统；用具体媒介、材质、色彩和光向，不以创作者姓名代替设计。
2. 【角色与场景定义】：按首次出场编号，给身份/衣装、体型、初态、原生引用；场景写空间锚点、物品及光线。有对白再明确语言/音色；表演强度按用户要求。
3. 【角色比例强制约束】【角色状态特别说明】：各用短段列本包相关的比例、站位、附着、易漂移状态和先后触发；不照搬示例数值。必要风险可在相关镜头重复强调。
4. 【具体情节描述】：阶段用“第一阶段：起止秒数【阶段名】”，下设“◈ 运镜与画面描述：”；每镜用【镜头①——景别，运镜】（起止秒数）并连续编号。一个连贯段落写当前状态、可见动作/反应、起幅→揭示→落幅及终态；按观察任务切镜，保持快慢与景别差异。
5. 每阶段另列“◈ 音效：”，对应环境、动作、人声原句与停顿；不把制作注释当台词。
6. 【全局补充（结尾）】：简述镜头逻辑与节奏、声音策略、针对性禁止项、最终画面/声音和转场。未指定则在最后可见画面自然结束，不额外加黑场、片尾卡或彩蛋。

阶段/镜数由内容决定；明确一镜到底或独立单镜时保留依据。1—3秒内部镜头可成立，不因独立生成4—8秒的适配范围删短镜。默认先按[timing](timing.md#先核算朗读再排15秒大段)核算朗读，再排15秒多镜包；包内切镜不另开生成任务。六项视觉设计融入正文，表格只保留[交接所需列](director.md#默认交付专业分镜表)。

### 编号、引用与重复强化

角色写“1. 角色名：”，主要区块用【】；身份编号与附件序号分开。每镜首次出现的主要角色、关键物品和场景旁带其实际原生引用，职责不可混用。平台实际支持@或{{Mixed n}}时沿用真实绑定，不手编标签/序号；未绑定或模拟引用在正文外注明。

统一设定每包集中写一次，各镜保留独立执行所需的身份/空间条件；只有状态易漂移或本镜涉及接触时再重复相关约束，不用“同上”替代必要内容。替换素材同步ID、版本、职责与受影响镜头，附件/连线/原生标签分别核对；能力不足按[generation](generation.md#生图输入的职责)记录。

### 全片提示词填写骨架

仅写新稿或获授权修订时填写；阶段与镜头按实际内容继续展开，不把骨架占位当成稿。

```text
整体视频风格设定：[媒介、材质、色调、动作物理与表演尺度]
光源设定：[时间、光向、光质]
光影系统：[明暗及材质受光]

【角色与场景定义】
1. [人物]：[真实引用、外形衣装、体型、初态；有对白时的语言音色]
场景——[名称]：[真实引用、空间锚点及关键物品]
【角色比例强制约束】
[本包相关比例、站位、附着]
【角色状态特别说明】
[本包易漂移状态、触发顺序、声音策略]
【具体情节描述】（按时间轴分镜，总计[总时长]秒）
第一阶段：[起止秒数]【阶段名】
◈ 运镜与画面描述：
【镜头①——景别，运镜】（起止秒数）
[主体及局部引用、当前状态、具体动作反应、镜头起落幅、光线和终态]
◈ 音效：
[本阶段环境/动作音、完整对白与停顿]
【全局补充（结尾）】
镜头逻辑与节奏：[与正文一致]
声音策略：[本片实际方案]
禁止项：[针对性错误]
结尾：[最后画面、声音及转场]
```

### 提示词正文交付检查

交付新写/修订的视频词时保留上述全部层次。待审核、草稿或未绑定不免除格式；未知能力/引用在正文外标明，不伪装就绪。资产词与首帧词不套此视频格式；用户另定格式则记录并按指定格式检查。

对实际保存版本运行对应只读检查：

```text
python "<skill-dir>/scripts/validate_excel_layout.py" "<已保存的.xlsx>"
python "<skill-dir>/scripts/validate_prompt_format.py" "<完整视频词.txt>" --mode full_film
```

默认Excel用第一条联合查两表、正文、包时长与表外朗读预算；纯文本用第二条，按交付选auto/single_shot/multi_shot/full_film，另核朗读和包长。自定模板另查布局，正文从权威单元格逐字导出检查。退出0为结构通过，1需修复，2读取失败。

核对区块完整有内容、阶段画面/音效、镜号连续、时间覆盖、结尾四项和无未填占位；再人工审读动作、观察任务、局部引用及声音对应。结构通过不代表创作、画面或音画验收；不能只查表头、标题数或用字符长度判质量。

## 视频提示词以已审核Excel为唯一执行来源

区分写稿与执行。用户已要求新写或授权修订时，交付明确标为“待审核”的稿，告知新增或变更的范围。实际执行先按[阶段规则](workflow.md#制作阶段与审核顺序)核对用户审核的工作簿版本、指纹与适用包号，再逐字读“生成任务”权威文本格；历史已审工作簿按原主表来源读取。主表提示词公式只用于展示，不用缓存、聊天或历史日志替代原词。

**缺词、未审核、版本失效或来源无法读取时，暂停该包并直接告诉用户包号、受影响镜号、原因和恢复办法。** 用户只要求执行时，不能顺手补写一个新稿或从分镜、首帧词和JSON拼词。允许独立工作继续；依赖该包实际输出的下游同时等待。

已审词逐字填入目标节点，提交之前读回平台实际保存的完整文本并比对。**读回不全、不可取得或有任何差异时，暂停该包并告知用户差异和下一步**，包括传输造成的换行差异。不能静默删词、润色、换音色、替换引用或在未核对时点生成。排除传输问题后，若能完整原样保存并重新读回一致，可沿用同版审核；需要改词时，先取得该改动的授权，在Excel形成新稿并取得该版审核后恢复。真实历史保留。

按[提交前原词检查](execution-checks.md#video_prompt提交前原词检查)使用现有审批和真实平台读回凭据；脚本匹配只是其中一项，另核对实际绑定、平台能力和生成授权。

## 视觉参数如何传给生成工具

首次设计或获授权改稿时，按[visual-style](visual-style.md)选同版可见方案，逐镜写落实与变化；实际提交已审词时不重新设计。首帧写构图、初态和光线，视频写动作、焦点与明暗变化。色号、焦距、光比、秒点、慢门/变速等是设计意图；需实际能力或后期实现，不能冒称硬控制。continue的真实尾帧不被风格要求覆盖。

## 表演包的实际适配

有角色动作/对白时，按[performance](performance-compiler.md)和[timing](timing.md)区分逻辑镜头、节拍、发声单元与生成片段。首帧写逐人视线、表情和回应，视频写之后的变化；不让身份图锁死表情，不复制已完成动作或重读台词。负向约束只针对本镜风险，专用字段须工具支持；不支持声音时保留独立配音/口型计划。实际生成后回放并逐句试听，声音按[sound](sound.md)。

## 白模预演与正式首帧分开

仅需要制作首帧/预演时读[first-frame-previz](first-frame-previz.md)。复用已核选图，不因写视频词额外做白模；白模颜色是预演标记，正式外观来自资产。无Blender的生图预演不称实测三维。多人/危机反应按[对应表演规则](performance-compiler.md#多人调度与危机反应)实看；continue原样用实际出点尾帧，规划尾帧仅用户明确要求时制作。

## 每镜完整提示词必须入表

交付Excel时，按[主表规范](director.md#默认交付专业分镜表)由主表“提示词”公式显示包词，完整正文只保存在“生成任务”权威格一次，必要预览和素材入口按表格职责展示。执行必需的声音/约束包含在本条词中，不靠跨表拼接。白模、正式首帧、视频词分别承担构图、外观和动态职责。

已有图的真实调用词、输入附件与版本作为历史证据；后补重建词标规划/未执行，旧记录缺失则注明，不伪造历史，也不自动判当前图不可复用。未知资产、模型或上游尾帧标缺项/待上游；无需的阶段或对白注明不适用，不为填表扩展制作。

## 每片段提示的内容

每段写：实际起态→剩余动作→摄影机/焦点→终态→必要连续性约束。多镜包按镜号、时间和切点组织；连续运动保留完整路径与速度趋势，不把相斥运动堆成一次动作。跨段续接才读[handoff](frame-handoff.md)，不重置动作或在完整发声单元中途分节点。光向/阴影按[lighting](lighting.md)核对；画外声音及字幕按工具能力与剪辑分工处理。
