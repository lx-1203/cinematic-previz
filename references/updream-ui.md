# Updream 界面补充操作

节点读取、搜索、改名、提示词、移动、连线和任务查询优先按 [updream-mcp.md](updream-mcp.md) 调用插件。以下经验用于本地上传、角色库、原站确认、未覆盖参数及 MCP 不可用时的明确界面操作，不将 DOM 点击作为日常节点操作的默认路径。

本页界面经验记录于 2026-10-19；模型参数、限制和价格仍需现场核实。原站提供的 canvas/gen WebMCP 是本插件调用的受限原生工具，不等于任意隐藏接口或页面状态访问。

## 与插件协作

- MCP 可用时，界面补充也沿用本任务已认领的项目。进入其他画布前重新确认 tabId、项目归属和任务范围。
- CANVAS_OWNED 表示其他工作仍拥有该项目，不能改用点击、另开标签页或复用对方 workspaceId 绕过。
- UNKNOWN_OUTCOME 时先读取实际节点与任务状态；不能因为没有立即看到界面结果而重复点击生成。
- 尚未接入 MCP 时可继续准备脚本和素材；如确需用户已授权的界面操作，先说明这一操作不受本机工作区锁保护，确认与其他正在编辑的工作不会冲突。不能声称具有 MCP 的隔离保证。
- 浏览器补充操作后重新读取节点状态，核对实际保存内容；只对当前已授权任务产生的结果作结论。

## 节点、画布和预览

- 继续下一段优先对已完成节点打开菜单，使用“克隆空节点”，保留模型和参考资产但不覆盖旧成片。先确认节点ID与空白状态，再重命名。
- 点击视频中心可能打开成片预览；预览遮挡时先关闭，不向后面的画布盲点。Esc不一定关闭，读取当前可见关闭按钮。
- 画布可能只渲染可见节点。查询不到节点时先检查缩放/位置，并用“适应屏幕”找回；不能据一次DOM缺失认定被删或反复新建。
- 页面可能处于独立剪辑界面，有“回画布”入口。用户同时操作时先协调，再读取最新状态；不要继续使用旧控件。浏览器超时先看结果，动作可能部分完成。

## 图片入口和顺序

- 角色库仅放白底身份资产。普通镜头画面从图片参考入口添加，专用首帧模式则使用其真实首帧槽。
- 普通本地上传曾经过：图片菜单→上传→本地上传→选择本地文件。切到“本地上传”页签不等于已经打开文件选择器；读取当前界面后再触发选择。
- 在实际选择文件按钮前监听文件选择器，再传绝对路径；不要点隐藏file input。批量上传后核对每张缩略图与实际序号，不能按旧序号写提示词。
- 保留不变身份资产，替换过期的首帧和视频参考。只移除当前节点附件，不误删角色库资产或原成片。

2026-10-19实测可辨别入口：角色素材提示旁的“上传”不能当镜头图片入口；普通参考从图片组的添加控件进入，再选“上传→本地上传→选择本地文件”。当次DOM提供`video-panel-image-dropdown-N`（N随已有图片数改变）与`video-panel-image-input`，只有重新观察当前DOM确认存在时才使用这些标记，不能硬编码N=3。菜单同名“上传”要先按所在弹层限定，不能凭全页同名按钮猜测。

文件选择事件在真正的“选择本地文件”动作前监听；事件等待预算须覆盖当前浏览器往返延迟，再检查isMultiple后批量选图。本轮一次10秒监听超时，60秒监听在正确入口成功取得选择器；入口不同，不能据此断言只改超时就解决所有上传问题。中断setFiles后先核对缩略图/URL，不重复上传。

## 成本查询与换算记录

- 2026-10-20，用户明确提供且本账号“积分购买”页档位交叉验证：**1人民币元＝100积分**，即每积分0.01元。页面例子600积分/6元、3000积分/30元、9800积分/98元。该记录适用于Updream当前已核实口径，不能套用到其他平台；不是把积分反向提现的承诺，也不是账号历史实际获赠积分的成本。
- 已有该换算口径时直接计算 `人民币费用=积分÷100`、`元/秒=积分÷100÷生成秒数`，无需每镜重开充值页；平台、兑换口径变化或记录与当前页面冲突时再核实。当前默认1元/秒相当于100积分/秒；1600积分/10秒为16元、1.6元/秒，仍须执行超预算选择。
- 通过顶部实际积分按钮展开详情，再进入“购买积分”只读查看兑换档位；停在查看，不勾选付费协议或点击支付。DOM快照可能含折叠的积分详情和历史条目，先确认面板真实展开，不能把隐藏旧内容当当前显示。
- 用“消耗明细”实际任务记录核对收费，记录已扣费用和当次报价；不要仅以账户余额差证明某个任务扣费，因为可能有其他任务或入账。当前配置的参考类型、音频、模型、时长变化仍须重新取得报价；上述兑换记录不能替代实时报价。

## 提示词、时长和证据

- 富文本提示框的fill曾出现追加旧文的情况。替换时在实际提示框内全选、删除、填写，再将页面正文与本地稿忽略排版空白比对；不要仅看字符数。
- 时长数字填写后失焦提交，再读参数摘要和报价。一次截图曾显示11秒而脚本为15秒；只有当前字段、报价、截图三者一致才交付确认。15秒和1650积分是某次配置，不是通用默认。
- 确认原生音频的实际选中状态；播放器静音、音量或浏览器声音与生成参数是不同层，不能看到播放器无声就断言没有音轨。
- 克隆空节点会继承旧参数，可能连“音频关闭”一起继承；每个新片段都核对音频选中态。控件只标“开启/关闭”且没有ARIA状态时，可只读检查可见按钮的active样式，并留配置证据；不能把提示词里写“有声”当作开关已打开。
- 提交前核对所有参考视频的合计时长，而不只看成片时长。一次实测为两条参考合计30.2秒，被站点以15.2秒上限拦截；这是当次站点能力，不能写成所有模型的固定上限。需要多角色声线时，可用本地FFmpeg从原片剪出短样本并保留来源时间段，合并后完整解码、核对总时长，再替换节点附件及提示词中的真实序号。仅作声音参考时，明确不复制样本的动作、尾帧或内部拼接切点。
- 站点明确返回输入校验失败时，先核对没有任务启动，再修正对应输入；不要当作生成中反复点击。替换参考后重新核对报价；超出用户本次批准金额须先确认，不能沿用较低的旧报价。
- 截图应同时让用户看清参考、模型、时长、画质、音频与价格，完整提示词另存可读文本。截图和读取状态冲突时重新检查，不使用过期证明。
- 每次只做有限、能验证的操作；长延迟或超时后重新取状态，不盲目重试付费生成。保留待确认页面供用户接续。

本轮内置浏览器样本中，单次Playwright读取约21秒，操作加读取约43秒；不是固定产品时限，也不是插件基准。按实测耗时拆分调用，避免在60秒脚本中顺序塞入三四次慢往返，导致环境重置和重复加载长文档。应使用宿主支持的完成事件/等待机制，并保留句柄；出错先核对结果。一次“返回画布”和一次“克隆空节点”在调用超时后实际已生效，不能按超时认定未执行。接口替代范围见[低开销路由](updream-efficiency.md)。
