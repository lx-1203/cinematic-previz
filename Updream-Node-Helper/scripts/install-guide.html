还差一次浏览器确认，就能连接 Updream

✓ 运行环境已准备　✓ 本机服务已启动　✓ Codex 已配置　✓ 自动配对已准备

1．打开 Edge 的扩展管理

在 Edge 地址栏输入 edge://extensions，回车。Chrome 用户输入 chrome://extensions。打开“开发人员模式”，点击“加载解压缩的扩展”。

2．选择下面这个文件夹

复制路径，粘贴到选择文件夹窗口的地址栏，回车，再点“选择文件夹”。

这是本机专用扩展副本；加载后会自动配对，无需寻找或导入 JSON 文件。请保留安装目录，别把此文件夹分享给别人。

3．登录 Updream 并启用画布

  1. 在同一个浏览器打开 Updream，登录并进入你的项目。
  2. 点击浏览器右上角拼图图标，打开 Updream MCP Bridge。
  3. 结束未保存的输入后，点击 启用当前画布并刷新。弹窗应显示“本机 MCP 已连接”和画布工具数量。
  4. 返回 Codex，重载 MCP 工具或新开聊天，要求“检查 Updream 连接”。

此包面向 Windows x64 + Edge/Chrome。Codex 内置浏览器的扩展兼容性尚未验证。加载扩展是浏览器的原生确认步骤，安装器不会代点、移动鼠标、远程控制电脑或自动提交付费生成。下次双击桌面的 Updream MCP Bridge 可重新打开本引导并检查服务。
