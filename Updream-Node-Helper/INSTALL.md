# 双击安装说明

1. 下载 `updream-mcp-bridge-0.3.1-windows-x64.zip`，右键选择“全部解压”。
2. 打开解压后的 `Updream-MCP-Bridge`，双击 **install.bat**。不要直接从压缩包内部运行。
3. 等待本机服务与 Codex 配置完成，浏览器会显示中文安装引导。
4. 按引导在 Edge/Chrome 加载显示的扩展文件夹，再进入 Updream 项目，点“启用当前画布并刷新”。配对自动完成，无需导入文件。
5. 返回 Codex 重载 MCP 或新开聊天，要求检查 Updream 连接。

首次浏览器加载需要你确认，这是保留的原生安装步骤，不承诺静默安装。安装器只在你双击后运行，不遥控桌面，不自动登录账号，不提交生成任务。

如果窗口报错，它会停留显示原因。缺少 runtime/node.exe 或 bundle-manifest.json 表示下载了源码包或没有完整解压；请改用 Windows x64 发布资产。旧桥接仍有工作区或执行任务时，先正常结束工作再重试。现有未受本安装器管理的配置不会被强行覆盖。

安装目录默认是 `%LOCALAPPDATA%\UpdreamMCPBridge`。桌面快捷方式可以再次检查服务并打开引导。配对和备份只留在安装目录的 `.local`，不要分享该目录。
